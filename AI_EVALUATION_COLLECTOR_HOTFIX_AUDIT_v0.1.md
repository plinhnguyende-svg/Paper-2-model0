# Final evaluation collector hotfix audit v0.1

Status: PRE-HELD-OUT CORRECTION. No held-out scenario has been generated by this change.

After PR #12 was merged, a final dry audit of the full collector path found a
serialization defect that the earlier incomplete-collector tests did not
exercise. Pandas coerces the mixed nullable/integer `training_seed` column to
floating point, so RuleBased `None` becomes `NaN`. The collector then called
`json.dumps(..., allow_nan=False)`, which would reject the otherwise valid
3,600-row panel at final serialization.

The correction is intentionally narrow:
- normalize RuleBased `training_seed` back to JSON `null`;
- normalize AI training seeds back to JSON integers;
- refuse to overwrite an already-existing final panel;
- add a full synthetic collector regression test that constructs all 40 frozen
  shards, 200 scenarios and 3,600 treatment/policy rows, collects them, parses
  every JSONL row, and checks 600 RuleBased null seeds plus 3,000 integer AI
  seeds.

No checkpoint registry, seed schedule, metric, bootstrap procedure, Model-0
physical dynamics, PPO/training code, treatment architecture or held-out
authorization condition is changed.

The previously created evaluator ref
`ai-final-evaluator-v0.1-frozen -> 0c9c35b78c9740aa38f85a75a2ac383bcf2260ad`
must be treated as superseded for final execution if this hotfix passes audit.
It must not be moved. A new immutable evaluator ref will be created from the
audited hotfix head instead.
