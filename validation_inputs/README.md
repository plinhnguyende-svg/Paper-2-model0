# Recovered originals: historical validation inputs

Files in gate9 through gate13 preserve recovered original Python and LaTeX bytes.
They are not the current master specification and their old deployment-status
statements must not be mistaken for the latest evidence verdict.

The original input snapshots are stored separately under data/external/gate18/.
The replay runner copies them to their expected paths in temporary working trees.
`public_indexed_char_snapshot.csv` is the historical website-indexed input used
by those experiments, not a block-pinned on-chain observation. All agent choices,
prices, arrivals and producer outputs generated by these scripts are synthetic.

Run `python3 scripts/replay_original_economics.py` from the repository root after
installing NumPy, pandas, SciPy and Matplotlib. The runner uses temporary copies,
preserves these input files, reruns the original main workflows, compares the saved
small summaries and records logs. It does not run Foundry or blockchain RPC.

Local replay environment versions and archive SHA256 values are recorded in
results/gate18/original_replay_manifest.json. The local audit compared 27 actually
regenerated CSVs to original archived outputs; bulk panels are omitted from GitHub
to avoid presenting a large synthetic dataset as empirical data. CI compares the
small reference summaries committed under results/gate18/original_replay/.
